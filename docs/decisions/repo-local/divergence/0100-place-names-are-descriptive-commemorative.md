# ADR-0100: Place names are descriptive, not commemorative

- Status: Accepted
- Date: 2026-05-29

**Context.** The world needs a naming convention for places. The default real-world conventions name places after people, history, or numbers; a different rule was chosen for divergence.

**Decision.** Place names come from what is actually there — descriptive, emerged from use, not assigned: named after the linden tree, the wide building on the corner, the one with the blue door.

**Alternatives rejected.**
- *Commemorative naming — after dead people, colonized land, or numbers* — Explicitly excluded; names in divergence emerge from use not assignment, so a place is called what it is
