# ADR-0099: Character cards as artifacts, not portraits

- Status: Accepted
- Date: 2026-05-29

**Context.** Character content could be written as novelistic portraits explaining who the character is, or as in-world documents (logs, interviews, inventories) that reveal the character through evidence. A production method had to be fixed.

**Decision.** Build character cards as in-world artifacts (observation log, interview transcript, survey, room inventory) that reveal the character through evidence; the framing device surfaces who they are.

**Alternatives rejected.**
- *A novelistic second-person portrait of the character* — That is the author explaining the character rather than the character existing; the artifact form is preferred because it makes the character through evidence instead of exposition

**Consequences.** All character work proceeds via artifact framing devices; portrait-style prose is disfavored. Reinforces the no-omniscient-narrator contract at the character level. Mined from: /home/me/git/paragarden/divergence/CLAUDE.md (170).
