# ADR-0163: Simulation must be physiologically grounded, never arbitrary numbers

- Status: Accepted
- Date: 2026-05-29

**Context.** The Existence game sessions repeatedly produced game-designer-intuition numbers (invented probabilities, abstract 'points' systems, arbitrary wardrobe caps) that the developer rejected, culminating in a hardened design constraint.

**Decision.** Require simulation to be grounded in reality with cited evidence (PMID references for biophysiological claims) and forbid invented numbers/arbitrary caps; encode 'Never invent numbers' and 'always externalize decisions' in CLAUDE.md (Feb 19).

**Alternatives rejected.**
- *Game-designer intuition / arbitrary numbers and abstract points systems* — The agent was criticized for inventing probabilities and abstract points; the constraint hardened to 'the simulation must be grounded in reality, not in game-designer intuitions,' with citation discipline required.

**Consequences.** All simulation/value claims must be externalized and citation-backed; arbitrary tuning is foreclosed. Pairs with the meta-rule 'every correction means a rule is missing.'
