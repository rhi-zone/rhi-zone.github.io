# ADR-0169: Real-system claims are quiet inline links with no attribution markers

- Status: Accepted
- Date: 2026-05-29

**Context.** The site's core mechanic is that fictional 2032 documents link to real present-day sources, collapsing the distance between 'this is a story' and 'this is happening.' The question was how to present those links so they don't break the fiction.

**Decision.** Every real-system claim links to the real source as a quiet inline link where the text itself is the anchor. No footnote markers, no 'Source:', no attribution. The fiction does not acknowledge the link and never fabricates one — find the real source or do not link. A document with unlinked real-system claims is incomplete.

**Alternatives rejected.**
- *Footnote markers, 'Source:' labels, or explicit attribution for cited real sources* — Visible citation apparatus makes the fiction aware it is linking, breaking the collapse of distance the mechanic depends on; 'The fiction doesn't know it's linking to anything.'
- *Bleak worldbuilding with no links to real sources* — 'Without the links, it's just bleak worldbuilding' — the links are what force the reader to contend that none of it was invented.

**Consequences.** All world documents must research the real version first and embed claims as unmarked inline links; completeness is defined by every real-system claim being linked.
