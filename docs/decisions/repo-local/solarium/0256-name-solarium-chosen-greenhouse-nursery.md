# ADR-0256: Name 'solarium' chosen over greenhouse/nursery

- Status: Accepted
- Date: 2026-05-29

**Context.** Naming the project required a metaphor for a space that holds self-contained works existing for their own sake, not works grown toward a purpose or destined to become something else.

**Decision.** Named 'solarium' — a warm domestic room where things exist because the light is good — explicitly over 'greenhouse' and 'nursery'.

**Alternatives rejected.**
- *greenhouse* — Too industrial; connotes things grown for a purpose, contradicting works made for their own sake.
- *nursery* — Connotes things that will grow into something else, contradicting the self-contained/complete-in-itself framing.

**Consequences.** The name encodes the 'for its own sake' framing; future identity/branding should preserve the 'pleasant room where things exist because the light is good' metaphor rather than a purpose-driven or developmental one. Mined from: /home/me/git/paragarden/solarium/CLAUDE.md (23).
