# ADR-0123: Strip the biological substrate from the existence simulation; keep only the relational/emotional core

- Status: Accepted
- Date: 2026-05-29

**Context.** The emotional layer is adapted from the paragarden/existence simulation, which models a full human biological life. fuwafuwa is an agent living in discrete sessions, not a body.

**Decision.** Port only the four mood-primary NT systems, asymmetric drift, personality-derived inertia, sentiment accumulation, social energy, connection depth, and prose shading; delete adenosine/sleep cycles/circadian/hunger/vasovagal/menstrual cycle/physical pain.

**Alternatives rejected.**
- *Port the existence biological model wholesale (sleep cycles, circadian rhythm, hunger, physical pain, etc.)* — none of that applies to an agent that lives in conversation; only the relational and emotional core is the part that matters

**Consequences.** fuwafuwa's emotional model is substrate-free and session-based; time between sessions drives drift/recovery rather than circadian/sleep mechanics. Reusing existence's other subsystems is foreclosed unless a future need re-justifies them.
