# ADR-0212: No decay, no archaeology framing: the world is permanently yesterday

- Status: Accepted
- Date: 2026-05-29

**Context.** Postmortem is a worldbuilding project about an earth emptied of all volitional agents. A core craft question was how to position the reader in time relative to the emptying event. An 'after the apocalypse' / archaeological framing (ruins, long-ago collapse, the reader as later visitor surveying the past) is the genre default and would let the reader hold the absence at a safe temporal distance.

**Decision.** The world has no decay: it looks vacated yesterday and will look vacated yesterday in a thousand years. The project never specifies a time of event and never says whether state is actively held or simply unchanging. Archaeology framing is forbidden in all content — nothing happened 'long ago'; it always looks like yesterday.

**Alternatives rejected.**
- *Archaeology / post-apocalyptic framing (ruins, decay, collapse, reader as later visitor of a long-ago event)* — It lets the reader tell themselves it happened long ago and that they are safe, defusing the intended dread. The horror depends on the absence being present-tense and unbounded.

**Consequences.** Every entry must use a permanent-present register; no temporal distancing, no ruins, no rot. Open: whether anything actively maintains the state is left unknowable and the project commits to never answering it.
