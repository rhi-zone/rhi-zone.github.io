# ADR-0214: Refuse to commit to any explanatory frame for the unchanging world

- Status: Accepted
- Date: 2026-05-29

**Context.** Because nothing decays and machines keep running, the world invites an explanation: something maintains it, or it is simulated, or mental, or merely consistent-but-uncaused. A project could pick one of these handwaves to make the world internally accountable.

**Decision.** The project does not commit to any explanation. Whether something is maintaining the state is unknowable from inside, and the text never gestures at maintenance, simulation, or any explanatory frame. The handwaves are explicitly held as possible-but-unchosen; none need to be true for the world to be true.

**Alternatives rejected.**
- *Commit to a handwave — simulated / mental / consistent-but-uncaused / an active maintainer* — Committing to any explanation would resolve the unknown the dread depends on; the questions are meant to be felt and never answered. None of the explanations need to be true for the world to be true, so choosing one only forecloses the intended uncertainty.

**Consequences.** Content may never assert or hint at a cause or maintainer; the 'no-decay mechanism' and 'maintenance question' TODO items are bounded to stay unanswered.
