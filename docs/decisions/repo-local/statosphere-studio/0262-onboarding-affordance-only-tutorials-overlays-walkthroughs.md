# ADR-0262: Onboarding is affordance-only; no tutorials, overlays, or walkthroughs

- Status: Accepted
- Date: 2026-05-29

**Context.** Roleplay-sim usability rounds (layperson + naive) surfaced friction. The natural response would be to add explanatory tutorials or intro overlays.

**Decision.** User onboarding is handled by making existing capabilities self-evident through affordances, not by adding tutorials or explanations. Concept tutorials, intro overlays, and walkthroughs are explicitly out of scope per a design call.

**Alternatives rejected.**
- *Concept tutorials, intro overlays, and walkthroughs* — Explicitly ruled out per design call: "spoonfeeding is what makes a game tutorial shit"; capabilities should be self-evident via affordances instead.

**Consequences.** Polish work is constrained to affordance changes that survive any future IA redo; teaching surfaces (tutorials/overlays) will not be built. A Preview/Simulate engine is also held off as an engineering project, not affordance work.
