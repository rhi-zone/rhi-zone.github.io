# ADR-0044: No auto-memory: agent state lives in versioned CLAUDE.md, and handoff plans stay lean

- Status: Accepted
- Date: 2026-05-29

**Context.** Sustained fuwafuwa autonomous runs surfaced agent degradation that pterror diagnosed as operational, not model-level, on Mar 17. The Mar 13-15 quality reckoning had traced agent dysfunction to authoritative-looking artifacts that agents trusted without user oversight; the MEMORY.md purge extended this. Auto-memory files in ~/.claude/projects/ persist across sessions and agents write to them by default, but they are unversioned, invisible, undiffable, and unbackupable, violating the ecosystem's core principle that all state should be versioned and visible. Concurrently, the recently-introduced comprehensive handoff-plan convention was injecting stale context that produced false direction and pushback in reincarnate/crescent sessions.

**Decision.** Stop using the auto-memory system entirely; write behavioral changes directly to CLAUDE.md so all state is versioned and visible. Encode this as a negative constraint in the ecosystem's root CLAUDE.md and propagate it to all repos. Simultaneously tighten the handoff-plan convention: agents always rewrite plans with only up-to-date next tasks, pending tasks, and what-was-done-this-session (only when relevant), relying on the codebase (CLAUDE.md/README/TODO.md) to carry context rather than bundling full context summaries into the plan. Applies across all repos.

**Alternatives rejected.**
- *Continue using the default auto-memory system (~/.claude/projects/.../memory/MEMORY.md files) as the persistence mechanism* — Files are unversioned, invisible, undiffable, unbackupable; agents write to them by default and trust them without user oversight, violating the ecosystem's principle that all state should be versioned and visible
- *Comprehensive handoff plans that bundle full context summaries* — Carrying all context into the plan introduced stale reasoning and false direction, observed as striking pushback in reincarnate/crescent sessions

**Consequences.** Agent state must live in the checked-in codebase (CLAUDE.md), making behavioral changes versioned, auditable, and reviewable across all repos. Auto-memory is forbidden ecosystem-wide, removing a class of unaudited state accumulating where the user cannot see it. Handoff plans become a lean pointer to next work, not a context dump; existing plans written under the old convention need ecosystem-wide rewrites. (Reflected in current CLAUDE.md hard constraints around no auto-memory and plan-file handling.)
