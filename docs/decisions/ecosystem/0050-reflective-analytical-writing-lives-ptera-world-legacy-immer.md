# ADR-0050: Reflective/analytical writing lives on ptera.world; legacy is immersive-only

- Status: Accepted
- Date: 2026-05-29

**Context.** The hubris/legacy themes exist in two places: a self-aware 'hubris' collection on ptera.world (the author reflecting from outside) and the standalone legacy site (in-world worldbuilding). A line had to be drawn for where analytical writing about the themes goes, since both sites cover the same material.

**Decision.** Reflective/analytical writing (the author's framing, analysis, external commentary) goes on ptera.world's hubris collection. The legacy repo holds only immersive in-world worldbuilding. External/reflective pieces are explicitly excluded from legacy.

**Alternatives rejected.**
- *Keep reflective and analytical writing inside the legacy repo alongside the immersive content* — ptera.world is reflective and legacy is immersive; mixing the author's external voice into legacy breaks the immersion that defines the site. The distinction is the organizing principle: 'ptera.world is reflective. Legacy is immersive.'

**Consequences.** Any reflective or analytical writing is now off-limits in this repo and must be routed to ptera.world. Listed as a hard constraint.
