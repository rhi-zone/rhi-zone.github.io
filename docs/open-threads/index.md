# Open Threads

A registry of cross-project design questions that don't cleanly belong inside any single project's `TODO.md`.

**File here:** questions that touch the ecosystem boundary — spanning multiple repos, requiring a convention that needs to be consistent across projects, or remaining unresolved across multiple sessions without a clear owner.

**File in the project's `TODO.md`:** questions scoped to a single repo, implementation details, or items that will be resolved entirely within one project's context.
