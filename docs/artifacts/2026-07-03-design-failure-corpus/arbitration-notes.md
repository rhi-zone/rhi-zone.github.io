## Methods rule: instruction-provenance tagging
An induced pattern is admissible evidence about agent behavior only after diffing it against the control surface (CLAUDE.md, hooks, house rules in effect during the logged period). Tag each pattern:
- **instructed** — matches an explicit harness directive; evidence of instruction-following only; circular for capability-boundary claims.
- **emergent** — no instruction produces it; admissible.
- **contra-instructed** — occurred despite explicit instruction; highest evidentiary weight.
