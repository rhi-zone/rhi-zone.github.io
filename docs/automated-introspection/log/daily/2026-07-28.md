**Implemented sessions blame feature:**
- Matching algorithm: content-aware substring matching of session edits against git blame chunks; whitespace-normalized, file-path-aware, change-granular (not commit-granular).
- Attribution logic: groups consecutive lines blamed to same commit; matches against session `Edit`/`Write` calls with timestamp ≤ commit timestamp; substring-matches on `new_string` against chunk, `old_string` against prior-commit content.
- Three outcomes: matched (1 candidate), ambiguous (N candidates), unattributed (0 candidates); rejects matches on <6 meaningful chars (too generic).
- Module: `crates/normalize-sessions/src/blame.rs` + new `sessions blame` subcommand.
- Tests: end-to-end fixture with real git repo + fabricated session JSONL; all three outcomes validated.
