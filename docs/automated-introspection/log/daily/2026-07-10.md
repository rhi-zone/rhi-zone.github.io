## Sessions and Activity

### fractal

One primary session at 14:27:37 — a handoff implementation request followed by multi-stage agent work to verify repository state, audit the roadmap, and design the query combinator API.

**Subtasks completed:**
1. **Verify repo state** — Agent audit of git status, branch state, test suite (248 tests passing), recent commits, and design documentation state. Identified the design backlog from a 2026-07-10 session audit and confirmed master branch is clean except for one untracked artifact.

2. **Read roadmap handoff** — Deep analysis of the typed `query(...)` combinator task, the highest-priority item on the fractal roadmap. Extracted roadmap specification, surrounding context, existing handler model patterns, the discharge model mechanics, and the open design question: should query params ride `req.ctx` and the discharge model (parallel to path params), or be read-not-discharged at the leaf?

3. **Design query combinator** — Agent design work proposed the pragmatic frame: query params as leaf-level schema-carriers (like the existing `validated` for body), not as ctx-discharge requirements (like `param` for path). The design resolves the asymmetry (path params gate routing; query params don't) by using the same `MethodsMeta.schemas` seam that body validation already uses for projection into OpenAPI and generated client signatures.

**Design decisions reached:**
- Query params should NOT thread through the discharge model (`Omit`).
- Query should be a leaf constructor in `@rhi-zone/fractal-http`, mirroring `validated` 1:1 in shape.
- Schema (Standard Schema V1) types the query-read function's first argument.
- Composition with path params remains orthogonal.
- No new meta tag; no change to routing or pattern matching (query does not gate routing).
- Projection via existing `MethodsMeta.schemas` seam (same as body validation).

**Tangent discussion:** A user correction flagged a semantic slip — raw query strings are already typed (as strings); the design concern is transformation/coercion to structured types, not initial typing.
