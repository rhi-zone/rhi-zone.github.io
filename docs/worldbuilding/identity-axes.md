# Identity axes

A taxonomy of the dimensions along which a reader can misidentify a POV. Useful when designing reader-only reveals — the reveal can only be as sharp as the axis it lives on.

## The axes

| Axis | Reader default | Alternative truth | Leak channel |
|---|---|---|---|
| **Substrate** | biological flesh | silicon / energy / fungal / linguistic / informational | sensory register, what counts as injury, metabolism |
| **Species / kind** | human | non-human animal / engineered / alien / extinct hominid | proportions, gait, sense rankings, social categories |
| **Social position** | reader's contemporary defaults (gender, era, class, faction, language community) | any other configuration | what's named vs. assumed, what's marked vs. unmarked |
| **Scale** | human-sized, ~80yr lifespan | microscopic / planetary / millennial / mayfly | what's described as "fast," "old," "near" |
| **Cardinality** | one body, one mind | swarm / hive / committee / fork / network / none | pronouns vs. decisions, internal disagreement treated as normal |
| **Continuity** | same person across time | succession in one role / branching / discontinuous / reconstructed | memory texture, what's remembered vs. inferred |
| **Embodiment** | has a body, is in it | is the body / inhabits / disembodied / distributed | proprioception, what "here" means |
| **Agency** | volitional actor | acted-upon / process / weather / instrument | who initiates verbs; whether choices feel chosen |
| **Mind interior** | first-person subjective experience | simulated interior / no interior / interior belongs to someone else | which feelings get named vs. only behaviorally inferred |
| **Origin** | born of parents | made / emerged / always-was / a copy | what's treated as childhood, what's missing |
| **Mode of existence** | alive, present-tense | dead / hypothetical / remembered / fictional-within | tense slippages, what can be touched |
| **Ontological tier** | inside the story | outside it / one frame up / the reader themselves | meta-references that don't read as meta |
| **Role** | protagonist | antagonist / obstacle / NPC / setting / witness | what gets foregrounded vs. what the prose lingers on |
| **Relation to text** | character being narrated | narrator / author / addressee / the act of reading | whose voice the narration is *for* |
| **Self-knowledge** | knows what they are | wrong about it / doesn't know / actively avoids knowing | what's confidently asserted vs. carefully not examined |

## Three orthogonal questions per axis

For any axis, the design space is a cube:

1. What does the reader assume? (the default)
2. What is actually true? (the reveal)
3. What does the POV believe about themselves?

That third one is the lever. Four configurations:

- **POV right, reader wrong** — dramatic irony for the reader, none for POV. Easiest. POV never lies; the trick lives in what they don't bother to mention because it's obvious to them.
- **POV wrong, reader wrong, *same* wrong** — both fooled together. Reveal lands on both at once. Hard to keep reader-only.
- **POV wrong, reader wrong, *different* wrongs** — POV thinks A, reader thinks B, truth is C. Rare and rich.
- **POV right, reader right** — no misidentification.

## Compounding

Most strong examples combine 2–3 axes. One axis tends to feel like a gimmick; four collapse into incoherence.

## Soft-proof of exhaustiveness

Not a real proof. A structured argument with stated caveats.

**Structure.** Identity, for a reader, is the set of slot-values the reader has filled in to pick out the POV as a referent. To misidentify is to fill a slot wrong. So the axes are exhaustive iff they cover all the slots prose can force the reader to fill. That reduces the question to: what commitments does prose mechanically require?

Four sources of forced commitment, and every axis above maps to one:

| Source of commitment | Forces… | Covers |
|---|---|---|
| **Sortal language** (nouns, kind-words) | what kind of thing | substrate, species, social position, mode of existence |
| **Individuation language** (pronouns, tense, deixis, proper nouns) | how it picks out as one entity over time | cardinality, continuity, embodiment, scale |
| **Situational language** (prepositions, "here/now," genre frame) | where it stands relative to world and reader | role, ontological tier, relation to text |
| **Reflexive language** (interiority, modals, evaluative verbs) | how the POV relates to itself | mind interior, agency, self-knowledge, origin |

If sortal/individual/situational/reflexive is an exhaustive decomposition of identity claims (a fairly standard analytic move), then so are the axes.

**Caveats — why it's soft, not hard:**

1. **Medium-bound.** Prose has specific leak channels. Film, comics, games force different commitments (visible body, controllable input). A taxonomy of identity-misreading in games would include axes prose can't host (e.g. "are you the avatar or the system").
2. **Genre-bound.** Defaults shift over time. "Human vs AI" became a salient axis only recently; "alive vs dead narrator" became readable as ambiguous only after specific exemplars. New genre conventions create new misidentifiable slots.
3. **Reader-bound.** Slots only exist where readers have defaults. If readers don't import a default, there's nothing to subvert. Cross-cultural variance is real.

So: exhaustive *modulo medium (prose), modulo current genre defaults, modulo a reader who imports contemporary defaults*. New axes appear when any of those conditions shift.
