# Lessons

Durable, cross-cutting engineering lessons distilled from real work — reusable guidance that applies across multiple projects, not tied to any single app.

**File here:** a principle that generalizes beyond the work that surfaced it — calibration habits, verification discipline, orchestration patterns. Phrase entries as reusable guidance, not as a session confessional.

**File elsewhere:** ecosystem *design decisions* go in [decisions](../decisions/README); single-repo implementation notes go in that repo's `TODO.md`; internal session/activity analysis lives under [automated-introspection](../automated-introspection/README).

This collection is meant to grow. Add an entry whenever a piece of work yields a lesson worth carrying into the next one.
