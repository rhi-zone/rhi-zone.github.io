# Synthesis: July 7 – July 16, 2026

Ten days. The prior synthesis (June 24 – July 6) closed on the overconfidence reckoning turning
into installed machinery — the no-guessing bright line, the obligation-gap principle, the
persona-file rewrite from rules to embodiment — all landed but explicitly provisional, "under
live evaluation." This window is where that machinery gets exercised rather than authored: two
more disposition edits land in the first three days (guessing tightened from discouraged to
*forbidden, full stop*; a hold-your-ground reflex reframed to impartiality), and the window
closes with a disposition rule this very document is written under — never demand verbatim
reproduction from an agent. Underneath the harness work, five substrates ran a genuine
engineering sprint — fractal's routing model settled and then exploded into a twenty-projector
type-IR layer, crescent shipped a swath of async-I/O and standard-library correctness work,
graphlet crossed the finish line to a published 0.1.0, rainbow closed its reactive-primitive arc,
normalize grew a semantic-facts prototype — and almost none of it is visible in the ten daily
logs this synthesis was asked to read first. That gap is itself the period's most important
finding, and it opens the account below.

## The capture gap: daily logs undercount by a wide margin

The daily-log process reports **2026-07-07 and 2026-07-09 as fully quiet — "no sessions
recorded."** Git history says otherwise. On 07-09 alone, crescent landed 17 commits (a
cross-platform I/O readiness dispatcher, an epoll backend, a kqueue backend, plus nine docs/design
commits on platform capability boundaries and a concrete roadmap draft) and fractal landed 7
(verb-helper bundles, attribute-dispatch, a node-shape reshape). Neither project appears anywhere
in the 07-09 daily log. The same pattern recurs in smaller ways throughout the window: rainbow's
entire reactive-html/combinator arc (`2c2a5a9` through `50a0185`, nine commits) is dated 07-15 in
git but narrated under 07-14 in the daily log — consistent with a timezone-boundary artifact
(commits authored in `+10:00`, session logs apparently boundary-drawn against a different clock)
rather than misattribution, since the content matches closely. The 07-09 gap is different in kind:
it is not a one-day drift, it is two substrates' work absent entirely.

This means the picture below is not "what the ten daily logs describe" but that account
**corrected and filled in against git history**, per the task's own instruction to treat the
logs as a starting point rather than ground truth. The prior synthesis flagged a comparable
caveat about fuwafuwa's session-count doubling being a possible counting artifact; this window's
finding is sharper — real engineering work simply did not surface in the narrative capture for
at least one full day. Future analysts should treat "no sessions recorded" as a claim to verify
against `git log --since --until`, not a settled fact.

## fractal: routing model settles, then a twenty-projector type-IR sprint

fractal is the busiest single substrate this window, and it runs in two distinct registers
separated by a multi-day design-only stretch.

**Early window (07-08–07-12): converge the routing/dispatch model, then go read prior art.**
The daily logs (07-10 through 07-12) narrate this faithfully: a session opened by resolving the
query-parameter combinator question — query params are a leaf-level schema-carrier
(`validated`-shaped), not a discharge-model participant like path params, because path params gate
routing and query params don't. That decision sits inside a larger routing-model settlement
running underneath: `Node` reshaped to `{handler, children, meta}` (dropping the old `ops` field),
dead `dispatch()` removed, `ParamNode` replaced by a `fallback` field, `effectiveTags` replaced by
a `mapNodes` visitor, named routing keys DU-ified into `HttpDirective[]`/`DispatchMarker`
variants — a coordinated refactor landing 233 passing tests across 8 workspaces. Four parallel
agents then surveyed Effect-TS, tRPC, Hono, and Elysia for how each separates transport surfaces
from handler definitions (Layers, adapters, schema merging), written to
`docs/design/prior-art/`. The user pushed back twice on premature solutioning mid-survey —
*"can you please stop suggesting things especially without thinking them through first,"* *"why
do you keep trying to force progress"* — redirecting the session toward full problem-space
understanding before any commitment, a live instance of the ecosystem's anti-guessing disposition
operating on its own author.

**Late window (07-16–into 07-17): the type-IR sprint.** After a multi-day design-only gap
(07-13–07-15, no fractal commits), the 07-16 daily log records "codification and projector
migration" — the projection-model correction that projections are `Node ⇒ ProtocolType`
(type-boundary crossing) while convention transforms are `Node ⇒ Node` endofunctors and rewriters
are `ProtocolType ⇒ ProtocolType`, and the old tree-walk HTTP dispatcher retired in favor of
`HttpRoute`. What the daily log does not capture is the volume that follows immediately: 38
commits on 07-16 and 35 more on 07-17 build out a **concrete type-IR hierarchy** with, in
sequence, TypeRef extraction from TS types, a JSON Schema projector, then in rapid succession
projectors for SQL DDL, Protobuf, JTD, TypeScript, Zod, Valibot, OpenAPI 3.0, JSON Schema
draft-07, TypeBox, JSDoc, ArkType, Cap'n Proto, io-ts, Yup, Superstruct, Effect Schema, runtypes,
MySQL, MSSQL, JSON Schema draft-04, and OpenAPI 2.0 — plus derivation operators (`partial`,
`required`, `pick`, `omit`, `extend`, `nullable`, `withMeta`, `deepPartial`, `deepRequired`),
branded/opaque type support, discriminated-union detection, native intersection handling across
six schema libraries, and an AOT validator codegen path (`TypeCompiler.Code()`, zero runtime
deps). A `decisions.md` running log of settled design calls was started to hold the accreting
context. This is a build-out at a completely different register from the design-and-research
cadence of the window's first half — the type-IR layer converged from "surveyed" to
"twenty-projector-wide and codegen-capable" inside about 48 hours, almost entirely outside the
window this synthesis covers on paper (07-16 is the last day; 07-17 falls after) but visibly
launched from inside it.

## crescent: async I/O lands for real, and a batteries-wide correctness sweep

The prior synthesis left crescent in an honest viability crisis over its typechecker kernel — "I
don't know if this converges." This window, crescent does not resolve that crisis; it works
almost entirely on a different layer, and the volume is large enough that it constitutes the
window's least-visible major thread (see the capture-gap section above).

- **Cross-platform async I/O, built and landed (07-09–07-10).** A cross-platform I/O readiness
  dispatcher (`io_poll`), a macOS kqueue FFI backend, and epoll FFI fixes land 07-09; 07-10 follows
  with the load-bearing move — the async runtime switches from a **virtual-time to a real-time,
  poller-driven event loop** — plus extraction of a shared write-readiness primitive across
  epoll/kqueue and a `timeout_ms` parameter on `wait()`. This is the concrete implementation of
  the "cross-platform event loop" thread the roadmap docs (07-09) had just opened.
- **A batteries-wide correctness sweep (07-10), roughly a dozen fixes in one sitting.** Each
  follows the same shape — a stdlib module was silently violating its own error convention or had
  a latent bug, and got fixed and characterized: `glob` was discarding compile/match/filter error
  messages; `event.emit()` returned `false` instead of `(nil, errmsg)` on a bad name; `count_min`'s
  `reset()` zeroed heavy-hitter keys instead of clearing them; `chan.try_recv` couldn't distinguish
  "empty" from "has data" for `select()`; `utf8.codepoint()` threw instead of returning `(nil,
  errmsg)` and truncated multi-return; `sat`'s `dpll` dropped the collect table from `solve_all`;
  `text_diff`'s Myers diff had a v-array off-by-one; `deque` didn't return `(nil, errmsg)` on
  empty/out-of-bounds access; `hash`/`sqlite` had a pre-existing SHA1 hex sign-extension bug and an
  FFI string-concat bug. None of these are dramatic individually; together they read as a
  deliberate pass hardening the standard library's error-convention discipline across the board,
  not incidental bug-fixing.
- **Platform capability design (07-08–07-09).** A cluster of docs commits works out capability
  boundaries for the platform layer — swappability vs. plain I/O, attenuation, construction,
  dependency-inversion — plus a permission-dialog/grant-fatigue design thread and a corrected cap
  boundary framing ("swappability, not just I/O"). This is design-before-code groundwork for the
  substrate the 07-16 daily log later narrates directly.
- **Substrate taxonomy and platform sandbox (07-16, the one thread the daily log does capture).**
  A session reviews the relationship between crescent's notes/memory substrate, its
  interface/presentation layer, and its creation tool, mining a prior session (200 user messages)
  to confirm platform-isolation architecture against a sandbox design (SES-inspired, allow-list
  lockdown) and prior art in a sibling project's widget registry. A six-facet taxonomy is
  developed for component classification — state, position, orient, act, remember, think — with
  the question of whether all six are primitives or some are derived left open; an all-projects
  search for consolidation hints was interrupted mid-session and left unresolved. The same day
  also lands FTS5 full-text search support in the sqlite layer and two batches of persona
  simulations for UX validation.
- **Right at the boundary (07-17, just past the window): PTY FFI and terminal-mux design.** Worth
  naming as momentum: thin POSIX PTY bindings with a two-tier fallback and a terminal-multiplexer
  design doc land the day immediately after the window closes, alongside docs recording open
  threads from the substrates/roadmap session and a text-CRDT gap.

crescent's typechecker-kernel viability question — the prior window's dominant thread — gets no
resolution and barely a mention this window; the substrate visibly redirected effort toward
runtime/platform foundations (I/O, stdlib correctness, capability model, substrate taxonomy)
instead.

## normalize: decomposition audit closes clean, then a semantic-facts crate grows fast

normalize runs two separated arcs, both well-covered by the daily logs.

- **Main-crate decomposition audit (07-08).** Five parallel audit agents examined every
  candidate leak zone (similarity/clone code, sessions command wiring, CFG dataflow,
  scoring/extraction, the service layer) against an explicit extraction bar (multiple dependents
  or genuine standalone value). Verdict: the 84k-line main crate is legitimate CLI-surface
  breadth, not a reservoir of duplicated domain logic — six specific, scoped improvements (D1–D6)
  were identified and **all six implemented same-day**: a liveness solver and shared block/edge
  loaders moved into the facts crate, a fixture-test harness relocated, an LSH candidate-pair loop
  deduplicated across three call sites, two hand-rolled UnionFind implementations collapsed onto
  the crate's canonical one, a session-aggregation fold moved into the session-analysis crate, and
  a verbatim `normalize_path` duplicate removed. A crate was also renamed
  (`normalize-analyze` → `normalize-rank`) to match what it actually does. Two real bugs were
  caught along the way — an iterative Tarjan SCC implementation was popping its resume sentinel
  before child frames, collapsing every SCC to a singleton, and a stale test fixture predated a
  CommonJS-import feature addition. The session closed by tracing down the actual reason a large
  volume of CLI tooling is vendored in-tree rather than extracted: **marginal-cost thinking** — on
  a bare system without `jq` et al. on `PATH`, the vendored engines are sunk-cost dependencies
  already needed for first-class grep/jq/ast-grep features, so the vendored front-ends add
  approximately zero marginal cost against real marginal benefit. This reframes line-count as a
  bad proxy for extraction cost.
- **New feature work (07-15).** An index/aliasing push: a unified alias system with
  `@property`-style declarations, persisted `symbol_words` vocabulary table, per-symbol complexity
  and per-file churn persistence, and structural/vocabulary/cross-file entropy density metrics.
- **The semantic-facts prototype (07-15–07-16).** Built a fact IR (`Fact`, `TypeShape` enums)
  proving the thesis that structurally equivalent declarations in different languages lower to
  identical fact nodes — a TypeScript interface and a SQL `CREATE TABLE` converge to the same
  `Fact::EntityField` node for a matching column, verified against live grammars rather than
  guessed (`normalize syntax ast --compact` on fixtures). Extended with a `SubtypeRelation` enum
  (`Exact`/`Subtype`/`Supertype`) and an approximate-mode toggle for relational reasoning (e.g.
  `UUID ⊆ String`). The following day's commits show this consolidating fast — a
  `SemanticFactExtractor` trait with a registry, validator-schema extraction, configurable suffix
  stripping — plus two dependency-hygiene fixes catching a semantic dependency that had crept back
  into the (deliberately dependency-light) main crate. Two bugs were caught and fixed during
  testing: alias-map key canonicization on insert, and enum-variant sort/dedup consistency.

## The harness/disposition thread: from "forbidden, full stop" to "never demand verbatim"

github-io's own commits this window form a tight, continuous arc — the direct continuation of the
prior period's overconfidence reckoning, now iterating on its own wording under further pressure.

- **07-08: guessing tightened to an absolute prohibition.** The disposition bullet moves from
  exploratory ("guessing is discouraged, prefer to ask") language to *"Guessing is forbidden, full
  stop. Not discouraged, not a last resort — forbidden."* The same session makes speculation-marking
  universal — any speculative content, prompted or not, must be marked as speculation and never
  handed back as settled — and separately removes a "Delegation & relay" section and a stray
  formatter-instability source in the propagated harness region (stopping needless churn across
  every receiver on each propagation run).
- **07-09: generation anchoring named as a constraint.** A new hard constraint: when a task
  involves choice, think it through *before* producing candidates, because whatever comes after a
  generated candidate tends to rationalize the anchor rather than solve the actual problem; if an
  anchor is noticed after the fact, discard and re-derive rather than patch forward from it. This
  is the current CLAUDE.md's "Generation anchors" bullet, and it reads as the generalized lesson
  from the prior period's design-it-twice removal — not "run two candidates," but "don't let the
  first candidate's shape steer the ones that follow."
- **07-10: hold-your-ground reframed to impartiality.** A disposition edit shifts the agent's
  stance on design pushback from *defending* a position under challenge to laying out tradeoffs
  without favoring the one it produced — the current CLAUDE.md's *"the agent is impartial about
  design choices and suggestions — it lays out tradeoffs, not verdicts."* A companion doc traces
  the evolution of the pushback-disposition rules that led here, an explicit self-audit of the
  control surface's own history (mirroring the practice the current CLAUDE.md's meta-section
  prescribes: repair or add a principle, never bolt on a patch).
- **07-16: a rule against demanding verbatim agent output.** The window's final harness commit —
  and the one this very report is written under, per its own instruction not to reproduce
  subagent output verbatim — installs the principle that routing content through an agent for
  echo is indirect, expensive, and silently truncates at output limits; an agent does work, not
  transcription.

Two other threads ran alongside the disposition edits without being disposition work themselves:
a **stateful scaffolding tool for agent-driven repo creation** was built (07-16, four commits) —
bun/godot/docs/static templates plus a propagation-lists step, with stale CLAUDE.md template
references removed and design goals relocated to the README — and the **skill-recipient list was
maintained** (a private repo removed from the list mid-window per the last synthesis's residual
tracking, another added). One commit (`e8fdf63`, "remove private project reference from public
repo") is a live instance of the public-repo privacy bright line firing in practice, not just
being described in policy.

## Cross-cutting patterns

1. **Design-before-code discipline held under real pressure twice.** fractal's user pushed back
   twice mid-survey on premature solutioning (07-12); the 07-13 reflection day ended on "research,
   not conclusion." Both are the impartiality-shift disposition (installed 07-10) operating live,

   (07-08–09) and rainbow (07-15) both ran a feature arc to a named completion point and then

   failure the control surface was built to prevent — acting on an unverified read rather than the
