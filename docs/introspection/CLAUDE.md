# CLAUDE.md — docs/introspection/

## Scope

This directory contains **only** the rhi ecosystem's own internal Claude Code introspection workflow:

- `log/daily/YYYY-MM-DD.md` — daily session summaries generated per the process in `README.md`
- `log/YYYY-MM-DD.md` — weekly snapshots over ecosystem projects, named by end date
- `log/synthesis-*.md` — cross-cutting pattern analysis over ecosystem work
- `investigations/` — structured multi-hypothesis investigations into ecosystem-internal issues

All content must reflect work on ecosystem projects (rhi-zone, exo-place, ptera-world, para-garden, or direct personal infrastructure). The introspection process is described in `README.md` — entries must be generated by that process.

## Hard Constraints

- Do NOT write documentation, retrospectives, or postmortems for external/non-ecosystem projects here. That material belongs in the affected project's own repo.
- Do NOT write general scratch notes, design drafts, or planning docs here. Those go in `docs/` proper or the relevant project repo.
- Do NOT add sidebar/nav entries in `.vitepress/config.ts` for `CLAUDE.md` or other non-page files.
